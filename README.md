# StudyLens AI

StudyLens AI is an AI-powered study assistant designed to help students understand and organize their study material more efficiently.

## Features

- AI-powered study assistance
- Study material analysis
- Automatic summaries
- Personalized learning resources
- Simple and user-friendly interface

## Technologies Used

- Java
- Maven
- AI / API Integration
